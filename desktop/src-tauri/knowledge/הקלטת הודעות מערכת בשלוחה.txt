#### **הקלטת הודעות מערכת בשלוחה**

הגדרת סוג השלוחה:

```ini
type=record_system_messages
```

ברירת מחדל מבקש לבחור באיזה תיקיה להקליט

ואיזה שם קובץ של הודעת מערכת

באם ברצונכם להגדיר מראש את השלוחה ליצירת הודעת מערכת =  ניתן להגדיר את מספר השלוחה

```ini
record_system_folder=/8/8
```

באם ברצונכם להגדיר יצירת הודעת מערכת, בשלוחה הראשית ניתן להגדיר

```ini
record_system_folder=main
```

באם ברצונכם להגדיר יצירת הודעת מערכת, בשלוחה של כל הודעות ברירת מחדל ברמת מערכת, ניתן להגדיר

```ini
record_system_folder=/Messages
```

הגדרת שם הודעת מערכת ליצרה

ברירת מחדל נותן ללקוח אפשרות להקיש ב4 ספרות איזה הודעת מערכת להקליט

באם ברצונכם להגדיר איזה קובץ מיידית יוקלט ניתן להגדיר

```ini
record_system_messages=M1000
```

בדוגמא יקליט את הודעת M1000

לאחר אישור ההקלטה, ניתן להגדיר:

```ini
say_record_number=no
```

ואז ישמע רק את ההודעה M1452 (ההודעה הוקלטה בהצלחה), וימשיך הלאה.

---

##### **הקלטת הודעה זמנית (M0001)**

**כברירת מחדל,** באם רוצים להקליט הודעה זו, משמיע תפריט להגדרות סוג תוקף (דקות / שעות / ימים / חודשים) ותפריט לכמות זמן רצויה.

בבחירת הקלטה ללא תוקף, המערכת תגדיר בשלוחה `post_with_time=yes` ללא תוקף,

כך שההודעה הזמנית תושמע ללא הגבלת זמן.

**הגדרת סוג תוקף כערך קבוע ללא תפריט**

כדי שלא ישאל סוג תוקף, יש להגדיר:

```ini
record_system_temp_validity_type=none
```

לסוג תוקף 'דקות', יש להגדיר:

```ini
record_system_temp_validity_type=minute
```

לסוג תוקף 'שעות', יש להגדיר:

```ini
record_system_temp_validity_type=hours
```

לסוג תוקף 'ימים', יש להגדיר:

```ini
record_system_temp_validity_type=days
```

לסוג תוקף 'חודשים', יש להגדיר:

```ini
record_system_temp_validity_type=months
```

**הגדרת כמות זמן כערך קבוע ללא תפריט**

לאחר בחירת סוג תוקף, מקליט ההודעה מתבקש להקיש כמות זמן מבוקשת.

כדי שיהיה כמות זמן כערך קבוע וללא תפריט, יש להגדיר:

```ini
record_system_temp_validity_quantity=30
```

בדוגמה, באם מקליט ההודעה בחר בסוג 'שעות', הזמן שיוגדר לשמיעת ההודעה הוא: 30 שעות.

---

##### **הגדרת מעבר בסיום**

ברירת מחדל לאחמ"כ חוזר שלב אחד אחורה ניתן להגדיר מעבר לשלוחה אחרת או ניתוק | ראה [כאן (ניתוב)](הגדרות גלובליות-הגדרות לכל השלוחות-הגדרות בכניסה לשלוחות ולמערכת-והסברים כלליים.txt#ניתוב) את האפשרויות להגדרה.

```ini
record_system_messages_end_goto=/5
```

בדוגמה ילך לשלוחה 5 שתחת התפריט הראשי

---

שימו לב:

ניתן להשתמש במודול זה כדי להקליט הודעות רגילות בשלוחה שתתחלף באופן קבוע.

לדוגמא: כדי להקליט את קובץ 000 שבשלוחה 1/2 יש להגדיר:

```ini
type=record_system_messages
record_system_folder=/1/2
record_system_messages=000
```

`M1009`	לשמיעת ההקלטה הקישו 1, לאישור ההקלטה הקישו 2, להקלטה מחודשת 3, לביטול וחזרה הקישו 4

`M2186`	הקלטת הודעות מערכת

`M2187`	אנא הקישו את שלוחת היעד וסולמית לסיום, לשלוחה פנימיות הקישו את הכתובת המלאה כאשר בין שלוחה לשלוחה הקישו כוכבית ולסיום הכתובת המלאה הקישו סולמית, לדוגמא לשלוחה אחת בתוך שלוחה אחת בתוך שלוחה שלוש הקישו שלוש כוכבית אחת כוכבית שלוש וסולמית לשלוחת הודעות ברירת המחדל הקישו כוכבית כוכבית וסולמית.

`M2188`	;שימו לב

;ההקלטה בשלוחה זו תחליף את כל המקומות במערכת בהם מושמעת הודעה זו, אלא אם כן תשימו הודעה מיוחדת בתוך השלוחה הספציפית

;לאישור והמשך הקישו 1

`M2190`	אנא הקליטו את ההודעה המיוחדת שלכם לאחר הצליל ובסיום הקישו סולמית

`M2191`	ההקלטה מבוטלת

`M2192`	שלוחה ראשית

`M2193`	שלוחת הודעות ברירת מחדל

`M2194`	יצרתם בהצלחה הודעת מערכת בשלוחה...

`M2195`	הודעה מספר

`M5010`	להגדרת שמיעת ההקלטה ללא תוקף, הקישו 0, להגדרת תוקף שמיעת ההודעה למספר דקות, הקישו 1, להגדרת תוקף שמיעת ההודעה למספר שעות, הקישו 2, להגדרת תוקף שמיעת ההודעה למספר ימים, הקישו 3, להגדרת תוקף שמיעת ההודעה למספר חודשים, הקישו 4

`M5012`	הקישו את מספר השעות לתוקף שמיעת ההודעה, ולסיום הקישו סולמית

`M5013`	הקישו את מספר הימים לתוקף שמיעת ההודעה, ולסיום הקישו סולמית

## סעיף 2

עדכון 17/08/2020:

ברירת מחדל נותן ללקוח אפשרות להקיש 4 ספרות בלבד.

אם ברצונכם לאפשר הקלטות המשך הגדירו:

```ini
record_system_messages_plus=yes
```

שימו לב שבמקום מקף צריך להקיש על כוכבית
