## קישורים לתוספים שניתנים להגדרה בכל מודול

ב"ה.

סוג השלוחה:

```ini
type=sip
```

מחייג למספר יוזר של המערכת.  ניתן להגדיר לאיזה מספר חשבון של המערכת הוא יחייג:

```ini
account_dial_number=3
```

או לחלופין, להגדיר שיחייג למספר שלוחה מסויימת במערכת:

```ini
account_dial_extension=495
```

בשימוש עם מספר שלוחה ניתן להגדיר להוציא את השיחה **לכמה** מספרי שלוחות בו זמנית, הראשון שיענה השיחה תפסיק לצלצל לשאר.

יש לשים את מספרי השלוחה מופרדים בפסיקים. למשל:

```ini
account_dial_extension=4652,496,111,65974,4848,4545,5454,45454,5851
```

את מספרי השלוחות של החשבונות ניתן להגדיר באתר בלשונית "מרכזיה עסקית".

ניתן להגדיר מוזיקה בהמתנה בחיוג:

```ini
sip_music_on_hold=שם המוזיקה בהמתנה
```

ניתן להגדיר הקלטת שיחות נכנסות:

```ini
sip_record=yes
```

ההקלטות ישמרו בסל מחזור תחת תיקיה `SIPRecordIn`.

ניתן לבקש שליחה למייל:

```ini
sip_send_mail=yes
```

ברירת מחדל שולח למייל המוגדר במערכת. ניתן להגדיר למייל אחר:

```ini
sip_send_mail_to=my@yemot.co.il
```

כברירת מחדל, המערכת שומרת דו"ח שיחות (נמצא בתיקיית SipLogs)

כדי לבטל את שמירת הדו"ח בשיחות נכנסות יש להגדיר

```ini
sip_ymgr_logger=no
```

**זמן חיוג**

ברירת מחדל מחייג 35 שניות, אם רוצים להגדיר זמן אחר, ניתן להגדיר

```ini
sip_timeout=23
```

כאן בדוגמה רואים שזמן ההמתנה יהיה 23 שניות.

לאחר ההמתנה יעבור לסיום, וכדלהלן.

**מעבר בסיום בשלוחה**

ברירת מחדל לאחמ"כ חוזר שלב אחד אחורה ניתן להגדיר מעבר לשלוחה אחרת או ניתוק | ראה [כאן (ניתוב)](הגדרות גלובליות-הגדרות לכל השלוחות-הגדרות בכניסה לשלוחות ולמערכת-והסברים כלליים.txt#ניתוב) את האפשרויות להגדרה.

**ההגדרה היא:**

```ini
sip_dial_end_go_to=/1/1/1/1
```

בחירת מחדל מבצע אותה פעולה גם אם השיחה לא נענת, ניתן להגדיר שאם הסתיים החיוג ולא היה מענה יושמע תפריט `M3519` המאפשר חיוג חוזר או סיום:

```ini
sip_tfr_redial_if_no_answer=yes
```

ניתן להגדיר מעבר לשלוחה אחרת/ניתוק באם לא היה מענה ללא תפריט חיוג חוזר:

```ini
sip_no_answer_goto=/0
```

ניתן להגדיר לאן ללכת/לנתק במידה שלא היה מענה כתוצאה מזה **שזמן החיוג נגמר**:

```ini
sip_timeout_goto=/1
```

#### מתקדם:

ברירת מחדל, ישנה צורה מסויימת שהמזהה של השיחה (זיהוי) נשלח, ישנם טלפונים שלא אוהבים את זה, וכל השיחות נראה שהם נכנסות מהמספר של המערכת, ניתן לשנות את הצורה של שליחת הזיהוי:

```ini
reverse_caller_id=yes
```

ברירת מחדל, נשלחים כותרות (headers) עם מידע על השלוחה, מזהה השיחה, ועוד. ישנם טלפונים או ראוטרים שזה גורם לכך שלא יכנסו שיחות נכנסות בכלל, ניתן לבטל את שליחת הכותרות:

```ini
sip_not_send_spacel_headers=yes
```

---

## סוג מערכת "חיוג SIP":

#### מחייג לשלוחת הSIP של המערכת

יש לשים ערכים בקובץ `sip_configuring.ini` שתחת השלוחה הראשית. לא ניתן להגיע לקבצים דרך האתר הרגיל - יש לבצע את הפעולה דרך האתר החדש.

ערכים אפשריים בקצרה, כי זה דומה לערכים שאפשריים בשלוחה:

```ini
sip_music_on_hold= # מוזיקה בהמתנה
sip_record=yes # להקליט
sip_send_mail=yes # לשלוח גם מייל
sip_send_mail_to=my@yemot.co.il # מייל שונה מהמערכת
reverse_caller_id=yes # לשנות את צורת הזיהוי בשיחות נכנסות
```

כברירת מחדל, המערכת שומרת דו"ח שיחות (נמצא בתיקיית SipLogs)

כדי לבטל את שמירת הדו"ח בשיחות נכנסות יש להגדיר

```ini
sip_ymgr_logger=no
```

## הגדרות ליחידה הטלפונית - שיחה יוצאת מהחשבון:

את כל ההגדרות הכלליות יש להכניס לתוך קובץ `sip_out_configuring.ini` שתחת השלוחה הראשית. במידה שהמערכת מוגדרת על סוג מערכת "חיוג SIP" לא ניתן להגיע לקבצים דרך האתר הרגיל - יש לבצע את הפעולה דרך האתר החדש.

על מנת להפעיל הקלטת שיחות יוצאות יש להגדיר:

```ini
sip_record=yes
```

ההקלטות ישמרו בסל מחזור בתיקיה `SIPRecord`.

על מנת לבקש גם שליחה למייל יש להגדיר:

```ini
sip_send_mail=yes
```

בחירת מחדל שולח למייל המוגדר במערכת, ניתן להגדיר מייל מיוחד:

```ini
sip_send_mail_to=my@yemot.co.il
```

כברירת מחדל, המערכת שומרת דו"ח שיחות (נמצא בתיקיית SipLogs)

כדי לבטל את שמירת הדו"ח בשיחות יוצאות יש להגדיר

```ini
logger=no
```

מוזיקה בהמתנה במהלך השהייה של השיחה, בחירת מחדל מושמעת מוזיקה בהמתנה בחירת מחדל אם אתה מעבירים את הלקוח להמתנה, ניתן להגדיר מוזיקה בהמתנה מיוחדת לערוץ:

```ini
musicclass=המוזיקה שלכם.
```

על מנת לקבוע זיהוי יוצא למדינה ספציפית, יש להכניס הגדרה `sip_out_callerid_XX` כאשר במקום יש להכניס קוד מדינה בשתי אותיות.

למשל, ארה״ב זה US.

ואז, בערך, להכניס את הזיהוי (הוא צריך להיות זיהוי מאושר/מספר משנה במערכת כמובן) לפי תקן E164.

לצורך הדוגמא, אם רוצים להגדיר זיהוי יוצא לשיחות בארה״ב, מגדירים:

```ini
sip_out_callerid_US=+134770770770770
```

#### שיחה יוצאת מחשבון הSIP היא בעלות יחידה לדקה, מלבד אם משתמש בקידומת פנימית, להלן הסבר.

ניתן לחייג פנימית **לחשבון sip אחר בשרת**, שימו לב, זה רק לשלוחת sip אחרת, זה לא חייג למערכת תוכן אלא לשלוחת הSIP שלה.

אם ברצונכם לבצע חיוג לשלוחת SIP אחרת דבר ראשון צריך להתחיל את השיחה ב`*1`. במילים: אחד כוכבית, ואז המספר של השלוחה אילה תרצו לחייג. זה בעצם מספר המערכת של חשבון הSIP השני.

למשל, כדי לחייג לשלוחת הSIP של מערכת 0773137770 יש להקיש בטלפון שלכם בחיוג

```ini
1*0773137770
```

**במקרה של שיחה כזו אין כלל חיוב יחידות.**

ישנה אפשרות גם להגדיר חיוגים מקוצרים בחיוג לשלוחת SIP אחרת, למשל, אם אתם רוצים שבמקום לחייג כל פעם את המספר מערכת המלא בשביל להגיע לחשבון הSIP אפשר להכניס בקובץ `sip_speed_local_dial.ini` חיוגים מקוצרים.

דוגמא למופיע בקובץ:

```ini
1=0773137770
5=0773136666
29=0773137777
```

ואז ניתן לחייג בטלפון לפי הקיצור.

למשל, כדי להגיע לשלוחה `0773136666` אפשר לחייג ל:

```ini
1*5
```

כדי להגיע ל`0773137777` אפשר לחייג

```ini
1*29
```

ישנה אפשרות גם להגדיר חיוגים מקוצרים כללים - ממש תרגום של כל מספר למספק אחר. (מינימום של מספר זה 2 ספרות) זה בקובץ `sip_speed_dial.ini`

דוגמא למופיע בקובץ:

```ini
050000000=0773137770
100=0773137777
55=0733137770
```

ואז חיוג ל 050000000 יתחלף בזמן החיוג ל 0773137770

חיוג ל 100 יתחלף בזמן החיוג ל 0773137777

חיוג ל 55 יתחלף בזמן החיוג ל 0733137770

<a id="לתשומת-לב-התמיכה-בIAX-הופסקה-עקב-הפיתוח-שלמודול-SIP"></a><a id="post-27280"></a>
## לתשומת לב:התמיכה בIAX הופסקה עקב הפיתוח שלמודול SIP

## **לתשומת לב:** התמיכה בIAX הופסקה עקב הפיתוח של [מודול SIP](#קישורים-לתוספים-שניתנים-להגדרה-בכל-מודול)

עם זאת מכיון שיש לקוחות שיש להם כבר IAX שרשור זה לא נמחק

חיוג וקבלת שיחות דרך המחשב:

ב"ה,

לאחר בקשות של לקוחות רבים פיתחנו אופציה לחייג דרך המחשב על ידי חיבור IAX למרכזיה.

ישנם מגוון תוכנות המאפשר לחייג בIAX בינהם zoiper וכד'.

טכנולוגיית IAX דומה לחיוג SIP המוכר רק החיבור שונה.

ניתן במערכת:

- לקבל שיחות ללא חיוב יחידות מהמערכת שלכם למחשב\לכל חייגן IAX.
- להוציא שיחות מהמערכת שלכם דרך המחשב\מכל חייגן IAX עם חיוב יחידות.
- ניתן להקליט את השיחות של שתי הצדדים
- ניתן להעביר שיחה למספר אחר **תוך כדי שיחה עם לקוח של שיחות שמגיעות מהמערכת**.
- ניתן לצרף שיחות לוועידה.

לצורך קבלת השירות יש לפנות לשירות לקוחות עם הסבר מדוע יש לכם צורך לקבל גישה כזו.

כרגע השירות ניתן ללא דמי פתיחה, יתכן ובעתיד לפי שיקול דעת ההנהלה השירות יעלה כסף.

**כרגע השירות קיים רק במערכות בשרת ymt, yemot או בשרת ymtA.**

הסברים על ההגדרות במערכת:

## חלק החיוג **מה**מחשב:

בחיוג הראשון יווצר קובץ `iax_conf.ini` בתיקיה הראשית. בו ניתן להגדיר:

האם להקליט את השיחות: (בחירת מחדל לא)

```ini
iax_record=yes
```

השיחות נשמרות בסל מחזור.

האם לשלוח את ההקלטה למייל: (בחירת מחדל לא)

```ini
iax_send_mail=yes
```

בחירת מחדל שולח למייל של המערכת, ניתן להגדיר מייל אחר:

```ini
iax_send_mail_to=aa@aa
```

השיחות היוצאות בעלות יחידה לדקה.

## חלק החיוג **ל**מחשב:

ניתן להגדיר בכל מקום במערכת:

סוג השלוחה:

```ini
type=iax
```

ניתן לבחור שיקלט שיחות: (בחירת מחדל לא)

```ini
iax_record=yes
```

השיחות נשמרות בסל מחזור.

ניתן לבקש שישלח למייל: (בחירת מחדל לא)

```ini
iax_send_mail=yes
```

ניתן להגדיר מייל נפרד מהמייל של המערכת:

```ini
iax_send_mail_to=aa@aa
```

ניתן להגדיר מוזיקה בהמתנה:

```ini
iax_music_on_hold=XXX
```

**מעבר בסיום בשלוחה**

ברירת מחדל לאחמ"כ חוזר שלב אחד אחורה ניתן להגדיר מעבר לשלוחה אחרת או ניתוק | ראה [כאן (ניתוב)](הגדרות גלובליות-הגדרות לכל השלוחות-הגדרות בכניסה לשלוחות ולמערכת-והסברים כלליים.txt#ניתוב) את האפשרויות להגדרה.

**ההגדרה היא:**

```ini
iax_dial_end_go_to=/1
```

הניתוב מהמערכת למחשב ללא עלות יחידות
