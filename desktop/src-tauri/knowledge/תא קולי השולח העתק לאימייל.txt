# תא קולי השולח העתק לדוא"ל - voicemail_email
<a id="תא-קולי-השולח-העתק-לדוא-ל-voicemail_email"></a>

### **השארת הודעה ושליחה לאימייל**

```ini
type=voicemail_email
```

---

> ראו: [תוספים הניתנים להגדרה בכל מודול](<סדר פעולות בכניסה לשלוחה לפני המעבר למודול עצמו.txt#תוספים-הניתנים-להגדרה-בכל-מודול>)

---

באם רוצים שיכניס את ההקלטות לשלוחה אחרת ניתן להכניס ערך עם שם התיקייה

התיקייה אליה שולחים את הקבצים חייבת להיות קיימת, אחרת - שגיאה.

```ini
folder_move=5/7
```

באם רוצים שיקליט הכל רגיל , אבל בפועל לא ישלח לאימייל אלא רק ישאיר בתיקייה

```ini
emeil_send=cancel
```

ברירת מחדל ההקלטה נשמרת גם אם הלקוח ניתק השיחה ללא הקשה או אישור שלו.

ניתן להגדיר שאם הלקוח ניתק את השיחה ולא אישור ההקלטה לא תישמר:

```ini
voicemail_email_no_save_if_hangup=yes
```

באם רוצים לקבל את ההודעה והתראה לטלגרם יש להוסיף:

```ini
voicemail_email_send_telegram=yes
telegram_chat_id=מזהה הקבוצה
```

**להסבר מפורט על שליחה לטלגרם מהמערכות יש לעניין בשרשור [הבא](https://f2.freeivr.co.il/post/51967).**

שימו לב, האפשרות לקבל הודעה לטלגרם עוברת רק בשרתי פריווט,  ymta\ymtb!

אם רוצים שההקלטה תומר לטקסט ויצורף במייל, יש להגדיר

```ini
record_tts_to_mail=yes
```

(ההמרה לטקסט מחייב יחידות)

אם הלקוח בחר לבטל את ההקלטה לאן ללכת:

```ini
voicemail_email_record_cancel_end_goto=/
```

כדי לדלג על תפריט אישור ההודעה:

```ini
record_ok=#
```

אפשר להוסיף את זיהוי המתקשר (ברירת מחדל מספר טלפון) בשם ההודעה:

הגדרה היא:

```ini
voicemail_email_add_id_to_name_record=yes
```

ואז שמות ההקלטות יופיעו בצורה הבאה

001-0552123456.wav

000-0552123457.wav

הגבלת כמות ההודעות שניתן להקליט - בדוגמא, יתן להקליט עד הודעה מספר 025 (כולל)

```ini
voicemail_email_record_max=025
```

לאן ללכת אם לא ניתן להקליט כי התיבה מלאה

```ini
voicemail_email_record_max_end_goto=/
```

ישמיע `M3700` "תיבת ההודעות מלאה. לא ניתן להקליט כעת הודעות, אנא נסו ביום אחר"

ניתן להגביל תיבת ההודעות לפי הודעות ביום נוכחי:

```ini
voicemail_email_record_max_by_day=yes
```

כמובן שצריך גם להגדיר כמה להגביל:

```ini
voicemail_email_record_max=3
```

יווצר קובץ בשלוחה: `record_max_sys.ini` שבכל יום יהיה שורה עם מספר ההודעות שהוקלטו באותו יום:

```ini
12/07/2020=2
13/07/2020=4
```

ובכך תבדוק המערכת באם מוגדר כנ"ל האם ביום הנוכחי עברו את מספר ההודעות שמוגדר בערך `voicemail_email_record_max=3` ובכך תתן / לא תתן להקליט.

האימייל שאליו נשלח - והשם שיופיע באימייל זה כמוגדר בערכים של שם הלקוח וכתובת דוא"ל המופיעים בלשונית הגדרות משתמש באתר האינטרנט.

אם רוצים לשנות את האימייל, כך שההודעות ישלחו לכתובת אחרת מאשר מה שמוגדר באתר, ניתן להכניס כתובת אחרת בערכים הבאים

```ini
email_address=AAA@gmail.com
email_name=avraem
```

שליחה לשתי מיילים:

ניתן להגדיר בשלוחה

```ini
email_address2=mail@mail.com
```

כמובן לכתוב מייל תקין, וזה ישלח את ההודעה גם למייל הראשון וגם לשני.

קובץ `M0000` יושמע ראשון אם קיים בתיקיה

באם

```ini
say_first_one_time=yes
```

אז ישמיע את ההודעה רק פעם אחת לאותה תיקייה בכל שיחה

במודול זה גם אם מנתקים באמצע השיחה - הקובץ נכנס לתיקייה, ונשלח אימייל עד הניתוק.

אם רוצים שלא יהיה ניתן להקיש סולמית ליציאה מההקלטה ושמיעה של ההקלטה וכו'

אלא יקליט עד שהלקוח ינתק צריך להוסיף את הערך

```ini
stop_record_only_hangup=yes
```

**כותרת המייל**

ברירת מחדל הכותרת באימייל היא

אישור (מספר אישור) ניתן ל (טלפון) ביום (תאריך)

אם ברצונכם שהכותרת תהיה שונה ניתן להגדיר

```ini
email_title=השארת הודעות לקבוצות גדולות
```

בדוגמא הכותרת תכיל את המילים "השארת הודעות לקבוצות גדולות"

**החלפת שמות עברית בקבצים שנשלחים במייל**

קובץ `record_log.ini`

ערכי ברירת מחדל הם:

```ini
record_log=דו"ח הקלטות
Folder=שלוחה
DID=מערכת
IdType=סוג זיהוי
teudat_zehut=תעודת זהות
digits=הקשת ספרות
list=רשימה
phone=טלפון
enter_phone_list=רשימת טלפונים
EnterId=מספר זיהוי
ValName=שם
Phone=טלפון
Date=תאריך
Time=שעה
HebrewDate=תאריך עברי
TotalTime=אורך בזמן
TotalSeconds=אורך בשניות
FileNumber=קובץ מספר
```

### **מעבר בסיום:**

ברירת מחדל לאחמ"כ חוזר שלב אחד אחורה ניתן להגדיר מעבר לשלוחה אחרת או ניתוק | ראה [כאן (ניתוב)](<הגדרות גלובליות-הגדרות לכל השלוחות-הגדרות בכניסה לשלוחות ולמערכת-והסברים כלליים.txt#ניתוב>) את האפשרויות להגדרה.

```ini
voicemail_email_end_goto=/6
```

בדוגמא יעביר את המאזין לשלוחה 6 מהתפריט הראשי

במודול זה משתמשים בהקלטות

`M1001` המקש שהוקש שגוי, אנא נסו שנית

`M1026` שלום ותודה

`M1060` אנא השאירו הודעתכם לאחר הִשַמע הצליל. לְסיום נתקו את השיחה או הַקישו סולמית

`M1061` לשמיעת ההודעה הקישו 1, לְאישור הקישו 2, להקלטה מחודשת 3, לביטול וחזרה הקישו 4.

`M1305` ההודעה קצרה מדי

`M1306` ההודעה מבוטלת
