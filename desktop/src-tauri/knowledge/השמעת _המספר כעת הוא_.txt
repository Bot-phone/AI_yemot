# "המספר כעת" לתור (לדוגמה במרפאות, בדואר) והשמעת קופונים קבועים - number_now_is
<a id="המספר-כעת-לתור-לדוגמה-במרפאות-בדואר-והשמעת-קופונים-קבועים-number_now_is"></a><a id="topic-67"></a><a id="post-88"></a>

```ini
type=number_now_is
```

השמעת מספר המוגדר להשמעה עכשיו

יכול לשמש מרפאות שרוצים להשמיע ללקוח מה מספר התור שכעת בפנים

או דוגמא נוספת - לעדכן קופון כל שהוא, אם אפשרות לעריכה מידי פעם.

המערכת מודיע הודעה:

M1343	המספר עכשיו הוא

המספר המושמע הוא המוגדר בערך

```ini
number_now_is=1050
```

בדוגמה זו ישמיע את המספר 1050

באם לא מוגדר הערך ישמיע

M1344	"המספר לעכשיו עדיין לא הוגדר" והמערכת מחזירה את המאזין לתפריט אחד למעלה

באם המתקשר הוא המנהל המוגדר בערך

```ini
phone_admin_folder=0501234567
```

אז המערכת תשמיע את המספר העכשיו כמו ללקוחות, ולאחר מכן תעביר את המנהל לערוך את המספר.

קובץ ההשמעה למנהל לעריכת המספר הוא:

M1345	"אנא הקש את המספר להשמעה

לביטול עריכה  הקש כוכבית וסולמית"

לאחר העדכון המערכת מחזירה את המנהל לתפריט הקודם.
