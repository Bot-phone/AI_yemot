# הגל השקט + היסטוריית אזעקות
<a id="הגל-השקט-+-היסטוריית-אזעקות"></a>

**הגל השקט לאזעקות ברחבי הארץ כולל צבע אדום:**

```ini
type=oref_alerts_quiet_wave
```

ברירת מחדל, משמיע כל 15 שניות בערך ביפ על מנת לתת חיווי למאזין, ניתן לבטל את זה ויהיה שקט לגמרי:

```ini
oref_check_quiet_wave_no_play_beep=yes
```

---

**היסטוריית אזעקות:**

```ini
type=oref_alerts
```

---

<a id="השמעת-אזעקות-בזמן-אמת-להטמעה-בכל-מודול"></a>
## השמעת אזעקות בזמן אמת להטמעה בכל מודול:

**השמעת אזעקות בזמן אמת להטמעה בכל מודול:**

```ini
oref_check=yes
```
