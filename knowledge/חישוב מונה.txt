# מודול חישוב מונה
<a id="מודול-חישוב-מונה"></a><a id="topic-107"></a><a id="post-138"></a>

במודול זה ניתנת אפשרות ללקוח לעדכן את מספר המונה העכשווי, המערכת תשמיע את ההפרש מהעדכון הקודם ותשמיע את הסך לתשלום לפי הסכום המוגדר לכל יחידה. כמו כן המערכת תשמיע את המחיר הקבוע לתשלום ואת הסה"כ לתשלום.

הגדרת המודול

```ini
type=counter_calculator
```

הגדרת המחיר ליחידה

```ini
counter_calculator_unit_price=1.5
```

בדוגמא כאן המחיר ליחידה מוגדר ל-1.5 ש"ח.

הגדרת סכום קבוע המתווסף לכל עדכון

```ini
counter_calculator_maintenance_price=10
```

בדוגמא כאן הסכום הקבוע מוגדר ל-10 ש"ח.

כברירת המחדל המערכת לא משמיעה את הסכום הקבוע. אם רוצים שתשמיע את הסכום הקבוע יש להגדיר

```ini
say_maintenance_price=yes
```

ניתן להגדיר שתהיה הגבלה - שניתן לעדכן רק פעם בחודש ובאיזה ימים בחודש ניתן לעדכן, בהגדרה זו

```ini
counter_calculator_open_time=10-20
```

בדוגמא כאן המערכת תתן לעדכן רק פעם בחודש בין הימים 10-20 לחודש הנוכחי.

מי שכבר עדכן החודש ויכנס שוב לשלוחה, ישמע הודעה שכבר עדכן. אם רוצים שישמע את הסכום לתשלום לפי העדכון האחרון.

ניתן להגדיר:

```ini
say_amount_billing_before=yes
```

ברירת מחדל לאחמ"כ חוזר שלב אחד אחורה ניתן להגדיר מעבר לשלוחה אחרת או ניתוק | ראה [כאן (ניתוב)](<הגדרות גלובליות-הגדרות לכל השלוחות-הגדרות בכניסה לשלוחות ולמערכת-והסברים כלליים.txt#ניתוב>) את האפשרויות להגדרה.

```ini
counter_calculator_end_goto=/1
```

באם השלוחה סגורה, או שכבר עדכן החודש, ברירת מחדל חוזר שלב אחד אחורה ניתן להגדיר מעבר לשלוחה אחרת או ניתוק | ראה [כאן (ניתוב)](<הגדרות גלובליות-הגדרות לכל השלוחות-הגדרות בכניסה לשלוחות ולמערכת-והסברים כלליים.txt#ניתוב>) את האפשרויות להגדרה.

```ini
counter_calculator_close_end_goto=/1
```

---

כל העדכונים נשמרים בקובץ counter_calculator_log.ymgr ומומר לדו"ח counter_calculator_log.html.

ניתן לערוך את המילים לדו"ח html בקובץ counter_calculator_log.ini

להלן המילים

```ini
Folder=
    Phone=
    IdType=
    EnterId=
    ValName=
    Date=
    Time=
    HebrewDate=
    AmountBillingBefore=
    AmountBilling=
    AmountBillingAfter=
    AmountMaintenancePrice=
    AmountBillingTotalToPay=
    Log=
```
