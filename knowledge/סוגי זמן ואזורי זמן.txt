| --- | --- |
| עלות השחר 120 | `alos120` |
| עלות השחר 90 | `alos90` |

| משיכיר | `misheyakir` |
| נץ החמה (אסטרונומי) | `sunrise` |
| סוף זמן קריאת שמע מג"א | `sof_shma_MGA` |
| סוף זמן קריאת שמע אדמור הזקן והגר"א | `sof_shma_GRA` |
| סוף זמן תפילה מג"א | `sof_shma_MGA` |
| סוף זמן תפילה אדמור הזקן והגר"א | `sof_tfila_GRA` |
| חצות היום | `chatzos` |
| מנחה גדולה | `mincha_gdola` |
| פלג מנחה (גר"א ואדמו"ר הזקן) | `plag_mincha` |
| שקיעת החמה | `sunset` |
| צאת הכוכבים (גאונים) | `tzeis` |
